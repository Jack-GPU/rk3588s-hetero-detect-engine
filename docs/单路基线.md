# 单路视频基线（阶段 1）

目标：用**固定本地 1080p 文件**跑通一路检测，留下可引用的延迟数字。  
本基线路径是：

`OpenCV 软解 → CPU letterbox → RKNN INT8 → CPU NMS`

**不是** MPP / RGA / dma-buf。后者做对照时另开脚本，口径不要混。

## 板上操作

```bash
# 1) 生成 10s 1080p30 测试片（从 bus.jpg）
python3 make_test_video.py --image bus.jpg --out bus_1080p30.mp4 --frames 300

# 2) 跑基线（预热 30 帧，其余计入分位）
python3 board_bench_video.py \
  --model yolov8n_int8.rknn \
  --video bus_1080p30.mp4 \
  --out-jsonl single_stream.jsonl \
  --out-summary single_stream_summary.json \
  --warmup 30
```

## 口径

| 字段 | 含义 |
| --- | --- |
| `infer_ms` | 仅 `rknn.inference` |
| `preprocess_ms` | BGR→RGB + letterbox |
| `decode_ms` | `VideoCapture.read` |
| `post_ms` | 解码框 + NMS |
| `e2e_ms` | 取帧到结构化结果写出 |
| `cpu_util_avg_pct` | `mpstat` 采样期间 100−%idle |

预热帧不进 P50/P99。样本数看 `measured_frames`。

## 简历怎么用

阶段 1 结束填：

- 路数 × 分辨率：`1 × 1080p`
- 端到端 P50 / P99：`e2e_ms`
- NPU 单帧：`infer_ms`
- CPU：`cpu_util_avg_pct`

有了这组数再做 RGA/dma-buf 对照（A/B）。
