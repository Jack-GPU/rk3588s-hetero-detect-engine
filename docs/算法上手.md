# 算法上手

目标：不训练，用官方预训练 **YOLOv8n** 走通：

`yolov8n.pt` → ONNX → **混合 INT8** `.rknn` → 板上出框

每做完一步对照「你会看到什么」。卡住时把终端完整输出留下来。

---

## 第 0 步：进容器

在仓库根目录：

```bash
./scripts/dev.sh
```

进容器后工作目录是 `/workspace`。自检：

```bash
python python/check_env.py
```

应看到 `rknn <class ...>`；有 GPU 时 `cuda=True`。

---

## 第 1 步：下载预训练权重

```bash
mkdir -p models
yolo predict model=yolov8n.pt source=assets/bus.jpg imgsz=640
```

把权重放到仓库（路径因版本可能不同）：

```bash
find /tmp /root -name 'yolov8n.pt' 2>/dev/null | head
cp "$(find /tmp /root -name 'yolov8n.pt' 2>/dev/null | head -1)" models/yolov8n.pt
ls -lh models/yolov8n.pt
```

---

## 第 2 步：导出 ONNX

```bash
python python/export_onnx.py --weights models/yolov8n.pt --out models/yolov8n.onnx
```

固定 `imgsz=640`、`batch=1`、`opset=12`、关闭 dynamic。

```bash
python -c "import onnx; m=onnx.load('models/yolov8n.onnx'); print([o.name for o in m.graph.output])"
ls -lh models/yolov8n.onnx
```

---

## 第 3 步：准备校准图

学习阶段 20～50 张即可；正式基线 200～500 张。

```bash
# 学习用
python python/prepare_calib.py --out data/calib --num 30

# 正式基线（COCO val2017，可复现）
python python/prepare_coco_calib.py --out data/calib/coco_val300 --num 300 --seed 42
```

`dataset.txt` 每行是**相对该 txt 所在目录**的图片名。

---

## 第 4 步：混合 INT8 转 RKNN

**不要用全 INT8。** 单输出里框坐标约 0～640、类别约 0～1，同一量化尺度会把类别压成 0。

```bash
python python/convert_rknn.py \
  --onnx models/yolov8n.onnx \
  --dataset data/calib/dataset.txt \
  --out models/yolov8n_int8.rknn \
  --simulate assets/bus.jpg
```

脚本会：`hybrid_quantization_step1` → 把检测输出相关层设为 FP16 → `step2` → 导出，并用 `assets/bus.jpg` 仿真。成功时 `cls_max` 应明显大于 0（例如 > 0.5）。

---

## 第 5 步：拷到板子并出框

板端 `librknnrt` 与 Toolkit2 对齐为 **2.3.2** 后：

```bash
# 宿主机
scp models/yolov8n_int8.rknn python/board_infer_yolov8.py assets/bus.jpg root@板子IP:~/

# 板上（已装 rknnlite / numpy / opencv）
python3 board_infer_yolov8.py \
  --model ~/yolov8n_int8.rknn \
  --image ~/bus.jpg \
  --out ~/bus_det.jpg
```

## 学习点

| 问题 | 自己验证 |
| --- | --- |
| 为什么先不训练？ | 预训练已经能出框；先打通部署链路 |
| 为什么要校准集？ | INT8 需要统计激活范围 |
| 为什么混合量化？ | 避免框/分类量纲冲突导致类别全 0 |
| 为什么固定 640 / batch=1？ | 和板上 RGA、NPU 输入形状对齐 |

3. 仿真或板上 `cls_max` / 检出框正常  

训练、三类标签重映射、板端零拷贝放到这之后。
