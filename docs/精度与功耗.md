# 精度与功耗（补充实测）

## INT8 vs FP32 mAP（coco8 sanity）

| | mAP50 | mAP50-95 |
| --- | ---: | ---: |
| FP32 Ultralytics | 0.898 | 0.630 |
| 板端混合 INT8 | 0.808 | 0.519 |
| 掉点（mAP50） | **0.090** | |

摘要：[`bench/logs/map_compare.json`](../bench/logs/map_compare.json)。  
coco8 只有 4 张 val，数字波动大，只作链路 sanity。正式掉点用：

```bash
python python/eval_map_coco.py prepare --out data/coco_val100 --num 100
python python/eval_map_coco.py fp32 --images data/coco_val100 --weights models/yolov8n.pt
# 板上
python3 eval_map_coco.py int8 --images coco_val100 --model yolov8n_int8.rknn --out pred_int8.json
python python/eval_map_coco.py summarize --fp32 runs/map_fp32.json --int8 map_int8.json
```
